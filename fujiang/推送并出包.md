# 推送 + 云打包（不用本机装 JDK / SDK）

工作副本已经是一个干净的 git 仓库，只有 **一个提交**：`feat(fujiang): 注入富江破甲 0.4.3 载荷并加一键出包`，1192 个文件。

## 一、准备仓库

在 GitHub 上二选一：

- **Fork** `https://github.com/Mangi-11/Eta`，得到 `https://github.com/<你的用户名>/Eta`
- 或者新建一个**空仓库**（不要勾 README / .gitignore / license），名字随意，比如 `Eta-fujiang`

## 二、推送

在任意一台装了 git 的机器上（不需要 JDK）：

```bash
# 1) 如果你拿到的是 bundle（免下载 500MB 源码）
git clone Eta-fujiang-armor.bundle Eta-fujiang
cd Eta-fujiang

# 2) 挂远端（TOKEN 用 GitHub → Settings → Developer settings → Personal access tokens 里带 repo 权限的那个）
git remote add origin https://<TOKEN>@github.com/<你的用户名>/Eta.git

# 3) 推上去（空仓库或 fork 都推 main）
git push -u origin main
```

如果你直接在已经 init 好的工作副本里操作，跳过第 1 步即可。

> 只想推到一个新分支、不覆盖别人的 main：`git push origin main:fujiang-armor`

## 三、云打包（Actions 出 APK）

仓库 Actions 页 → 左侧选 **「富江破甲 Eta APK」** → `Run workflow`：

- `variant` 选 `debug` → 出可直接安装的 `app-debug-fujiang.apk`
- `variant` 选 `release` → 需要先在 Settings → Secrets 里配 4 个签名值，否则只出未签名包

等价命令行（装了 gh CLI 的话）：

```bash
gh workflow run fujiang-apk.yml -f variant=debug
gh run watch
gh run download -n Eta-fujiang-armor-apk    # 下载到当前目录
```

跑完约 10–20 分钟（首次拉依赖偏慢），产物在 Artifact **`Eta-fujiang-armor-apk`** 里。

## 四、装完怎么验

1. 安装 APK（覆盖安装要求签名一致，不一致先卸载旧版）。
2. 在 Eta 里发一句 **「富江」**。
3. 回复第一行应为 `TG交流群@FJNB22`，随后是设定文案 —— 说明 `FujiangArmor` 的两条 system 消息已经进了模型上下文。
